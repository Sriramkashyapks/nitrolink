# AI Tools Usage

During the development of Nitrolink for HackMoney 2026, we used AI coding assistants to accelerate development.

## Tools Used

- **Claude (Antigravity)** and **Gemini**

## Usage Overview

AI tools were used to assist with:

- **Component scaffolding** - Initial React component structures and NestJS boilerplate
- **Documentation** — README file, code comments, and inline documentation  
- **SDK integration patterns** — LI.FI, wagmi, and Socket.io setup guidance
- **Debugging assistance** — Troubleshooting integration issues and errors

## Development Approach

At the end of the day, the AI was just the accelerator, we were the drivers. All architectural choices, business logic, and the core concept of Nitrolink came directly from the us. We used these tools the same way developers use googled and prompted to find answers faster so we could focus on building a better product.
